## 🚀 Key Concepts Practiced

### 🔹 Distributed Processing

* Processed data across partitions using `mapPartitions()`.
* Generated indexed records with `zipWithIndex()`.
* Compared partition-based processing with row-level transformations.

### 🔹 Join & Set Operations

* Generated Cartesian products using `crossJoin()`.
* Compared datasets using `exceptAll()`.
* Retrieved common records with `intersect()`.

### 🔹 Multi-Dimensional Aggregations

* Created summary reports using `cube()`.
* Performed hierarchical aggregations with `rollup()`.
* Compared the outputs of Cube and Rollup operations.

### 🔹 Performance Optimization

* Improved join performance using `broadcast()`.
* Compared broadcast joins with standard join operations.
* Examined execution plans for query optimization.

### 🔹 Array Processing

* Expanded array columns using `explode_outer()`.
* Compared `explode()` and `explode_outer()`.
* Filtered array elements using `array_contains()`.
