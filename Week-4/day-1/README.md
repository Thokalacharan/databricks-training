## 🚀 Concepts Practiced

### 🔹 DataFrame Creation

* Created an Employee DataFrame using PySpark.
* Defined the schema and loaded sample employee data.
* Explored the dataset using DataFrame operations.

### 🔹 Data Selection

* Selected required columns using `select()`.
* Retrieved specific employee details.
* Displayed relevant information for analysis.

### 🔹 Data Filtering

* Used `filter()` and `where()` to retrieve required records.
* Applied conditions based on salary, department, age, city, and gender.
* Combined multiple filtering conditions.

### 🔹 Column Transformations

* Added new columns using `withColumn()`.
* Renamed columns using `withColumnRenamed()`.
* Created conditional columns using `when()`.

### 🔹 Data Cleaning

* Removed unnecessary columns using `drop()`.
* Retrieved unique records using `distinct()`.
* Removed duplicate records using `dropDuplicates()`.

### 🔹 Sorting and Ordering

* Sorted data in ascending and descending order.
* Performed sorting using multiple columns.
* Organized employee records for better analysis.

### 🔹 Aggregations

* Grouped data using `groupBy()`.
* Calculated total, average, minimum, maximum, and count values.
* Generated summary reports using aggregate functions.
