## 🚀 Key Concepts Practiced

### 🔹 Column Creation & Conditional Expressions

* Added constant columns using `lit()`.
* Created conditional values with `when()` and `otherwise()`.
* Classified employees based on salary, age, experience, and department.

### 🔹 String Processing

* Extracted required text using `substring()`.
* Modified strings with `regexp_replace()`.
* Filtered records using `LIKE`.
* Retrieved specific records using `isin()`.

### 🔹 Range-Based Filtering

* Used `between()` to filter records within a specified range.
* Retrieved employees based on salary, age, joining year, and employee ID.

### 🔹 Data Reshaping

* Created summary reports using `pivot()`.
* Converted pivoted tables back into rows using `unpivot()`.
* Restructured datasets using `stack()`.

### 🔹 Window Functions

* Ranked records using `rank()`.
* Generated continuous rankings with `dense_rank()`.
* Assigned sequential numbers using `row_number()`.
* Retrieved previous and next row values using `lag()` and `lead()`.
